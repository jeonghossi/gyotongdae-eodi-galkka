==============================
 교통대 어디 갈까 — 로컬 버전 사용법
==============================

내 PC에서 직접 돌아가는 버전입니다.
Claude 없이도 쓸 수 있고, 폴더째 USB나 다른 PC로 옮겨도 됩니다.


------------------------------
 1. 실행하기
------------------------------

1) "실행하기.bat" 더블클릭
2) 검은 창이 뜨고, 브라우저가 자동으로 열림
   (안 열리면 주소창에 http://localhost:3100 입력)
3) 끌 때는 검은 창을 닫기

※ Node.js가 설치되어 있어야 합니다. (지금 PC에는 설치되어 있음)
※ index.html을 직접 더블클릭하면 데이터와 채팅이 안 됩니다.
   꼭 "실행하기.bat"으로 여세요.


------------------------------
 2. 친구랑 채팅하기
------------------------------

- 친구가 같은 와이파이에 있어야 합니다.
- 실행하면 검은 창에 이런 줄이 나옵니다.
    같은 와이파이에서: http://192.168.x.x:3100
- 이 주소를 친구에게 보내면 폰이나 노트북으로 접속할 수 있습니다.
- 처음 실행할 때 Windows 방화벽 창이 뜨면 "허용"을 누르세요.
  허용하지 않으면 친구가 접속할 수 없습니다.

채팅 규칙
- 익명 채팅입니다. 닉네임 없이 모두 "익명"으로 보입니다. (내 글만 "나")
- 메시지는 20초 뒤 사라지고, 어디에도 저장되지 않습니다.
- 내 PC를 끄면 채팅도 꺼집니다.
- 80자까지, 1초에 한 번까지 보낼 수 있습니다.


------------------------------
 3. 리뷰·추천·비추천
------------------------------

- 카드를 누르거나 "리뷰·추천 →"을 누르면 리뷰 창이 열립니다.
- 카드 위 "학생 추천 N"은 1주차 학생 추천 수이고, 추천·비추천은 따로 셉니다.
- 추천·비추천은 한 곳에 한 번만, 취소는 안 됩니다. (디시처럼)
  같은 PC(같은 IP)에서는 한 번만 누를 수 있습니다.
- 추천 5개 이상이면 "개념" 표시가 붙습니다.
- 리뷰는 닉네임 + 비밀번호로 씁니다. (닉네임을 비우면 "ㅇㅇ")
  지울 때 같은 비밀번호가 필요합니다.
- 닉네임 옆 괄호는 IP 앞자리입니다. 내 PC에서 쓰면 "(내 PC)".
- 리뷰는 5초에 한 번, 300자까지 쓸 수 있습니다.
- 누가 추천·리뷰를 하면 다른 사람 화면에도 바로 반영됩니다.

뭐 먹지? 골라주기 (맛집 탭 맨 위 "골라줘 →")
- 조건: 밥집만(카페·술집 빼기) / 1인 8천 원 이하 / 학교 앞만
  맛집 카테고리를 골라 둔 상태면 "그 카테고리만"도 고를 수 있습니다.
- "돌리기"를 누르면 이름이 돌다가 한 곳에 멈춥니다.
- 학생 추천과 사이트 추천을 많이 받은 곳이 조금 더 잘 나옵니다.
- 방금 나온 곳은 바로 다음 번에는 안 나옵니다.

지도로 보기 (맛집·숨은장소 탭, 개수 옆 "목록 | 지도")
- 지금 고른 카테고리·필터에 맞는 곳만 지도에 핀으로 나옵니다. 핀을 누르면 리뷰·네이버 지도로 갈 수 있습니다.
- 처음엔 "학교 앞"(캠퍼스 2.5km 안)이 보이고, 오른쪽 위 "충주 전체"로 넓힐 수 있습니다.
- 위치는 학생들이 올린 네이버 지도 링크에서 뽑았습니다. 링크로 위치를 못 찾은 곳은
  지도 아래 "지도에 위치가 없는 곳"에 따로 나옵니다.
- 지도 그림은 인터넷이 있어야 보입니다. (위치 목록: public/data/coords.json)

정보 제보 (사이트 위쪽 "제보하기 →", 또는 리뷰 창의 "이 정보가 틀렸나요?")
- 종류(정보 수정 / 새 장소 추천 / 폐업·이전 / 기타), 분류, 대상 이름, 내용, 연락처(선택)를 받습니다.
- 30초에 한 번만 보낼 수 있습니다.
- 제보 확인: 관리자 페이지의 "제보함" 탭 (아래 참고)
- 제보 저장 위치: storage\reports.json

AI 도우미 (오른쪽 아래 "✦ AI에게 물어보기")
- 이 PC의 Ollama 와 EXAONE 3.5(2.4b) 모델로 돌아갑니다. 인터넷·비용 없음.
  Ollama 가 꺼져 있으면 "AI가 꺼져 있어요"라고 나옵니다.
- 장소·정보 질문("8천 원 이하 밥집", "시내 가는 버스"):
  코드가 사이트 데이터에서 후보를 고르고, AI 는 그중 맞는 곳을 고르고 한두 문장만 씁니다.
  가게 이름·가격·시간은 AI 가 아니라 데이터로 만든 카드에 나옵니다 (지어내기 방지).
- 사이트에 없는 곳("스타벅스 있어?")은 "찾지 못했어요"라고 먼저 답합니다.
- 그냥 대화("심심해", "과제 힘들어")도 됩니다. 힘들다는 말에는 상담센터 꿀팁을 같이 보여 줍니다.
- 같은 와이파이의 친구도 쓸 수 있고, 한 사람당 한 번에 질문 하나씩만 처리합니다.
- 모델 바꾸기: 예) ollama pull exaone3.5:7.8b 로 받은 뒤 ai.js 의 'exaone3.5:2.4b' 를 바꾸고 서버 다시 켜기
- 보기 전용판(GitHub 주소)에서는 서버가 없어서 숨겨집니다.

관리자 페이지: http://localhost:3100/admin.html
- 들어가는 법: 사이트 화면에서 정해 둔 관리자 키를 키보드로 입력 (폰은 검색창에 입력)
  사이트에는 관리자 링크가 보이지 않습니다. 키는 이 파일에 적지 말고 따로 보관하세요.
- 키 바꾸기: 검은 창에서 node tools/set-admin-key.js → 새 키 입력 → 서버 다시 켜기
  (admin-key.local.json 에 해시만 저장되고, 이 파일은 GitHub 에 올라가지 않습니다)
- 주소창에 admin.html 을 직접 쳐도 "없는 파일"로 나옵니다. 키를 입력해야만 들어갈 수 있습니다.
- 서버를 켠 이 PC에서만 열립니다. 다른 기기에서 키를 입력해도 들어갈 수 없습니다.
- 한 번 들어가면 12시간 동안 유지되고, 관리자 화면의 "나가기"를 누르거나 서버를 끄면 다시 키를 입력해야 합니다.
- 키를 틀리게 입력하면 1분에 5번까지만 시도할 수 있습니다.
- 현황판: 지금 접속자, 처리 안 한 제보, 리뷰·추천 수, 추천·리뷰·비추천 많은 곳 순위
- 제보함: 제보 목록, 처리 완료 표시, 삭제
- 리뷰 관리: 모든 리뷰 보기·찾기, 욕설·광고는 비밀번호 없이 삭제
- 추천 관리: 장소별 추천·비추천 수, 조작이 의심되면 초기화
- 새 리뷰·추천·제보가 오면 화면이 저절로 갱신되고,
  새 제보는 서버 검은 창에도 "📮 새 제보 도착"으로 표시됩니다.

저장 위치: storage\reviews.json
- 이 파일을 지우면 리뷰·추천·비추천이 모두 초기화됩니다.
- 백업하려면 이 파일만 복사해 두면 됩니다.
- 비밀번호는 암호화되어 저장됩니다.


------------------------------
 4. 엑셀을 고친 뒤 반영하기
------------------------------

1) 정리된 엑셀(…_데이터.xlsx)을 고치고 저장
   ※ 시트 이름과 첫 줄(머리글)은 바꾸지 마세요.
   ※ 맛집 카테고리는 "맛집_카테고리" 시트에서 고치세요.
2) "데이터-갱신하기.bat" 더블클릭
3) 엑셀 파일을 검은 창에 끌어다 놓고 Enter
4) "완료"가 나오면 브라우저를 새로고침

※ 처음 한 번은 엑셀 읽기 도구를 설치하느라 인터넷이 필요합니다.


------------------------------
 5. 폴더 구성
------------------------------

실행하기.bat          웹사이트 켜기
데이터-갱신하기.bat   엑셀 내용을 웹사이트에 반영
server.js             웹사이트와 채팅을 돌리는 서버
public/
  index.html          화면 뼈대
  style.css           디자인
  app.js              동작 (필터, 검색, 채팅)
  data/places.json    맛집·숨은장소·꿀팁 데이터
  data/photos.json    숨은장소 사진 목록 (지금은 화면에 안 씀)
  data/coords.json    로드뷰 좌표
  images/             숨은장소 사진 6장 (지금은 화면에 안 씀)
tools/update-data.js  엑셀 → 데이터 변환 프로그램
storage/reviews.json  리뷰·추천·비추천 저장 파일 (처음 리뷰를 쓰면 생김)


------------------------------
 6. 알아둘 점
------------------------------

- 인터넷이 없으면 글꼴만 PC 기본 글꼴로 바뀌고, 나머지는 그대로 됩니다.
  (지도 보기·로드뷰 버튼은 인터넷이 있어야 열립니다.)
- 숨은장소 카드는 용도별 그림으로 보여 줍니다. 학생들이 올린 캡처 사진 6장은 images/ 에 남아 있지만 쓰지 않습니다.
