# 교통대 어디 갈까

국립한국교통대학교 충주캠퍼스 학생들이 직접 추천한 맛집 · 숨은장소 · 생활꿀팁을 모아 보여주는 웹사이트입니다.
학생 21명이 낸 정보 442개를 AI가 쓰기 좋은 표로 정리한 뒤(2주차 실습), 그 데이터로 만들었습니다.

👉 **바로 보기: https://jeonghossi.github.io/gyotongdae-eodi-galkka/**

> 위 주소는 **보기 전용판**입니다(GitHub Pages는 서버를 돌릴 수 없음).
> 맛집·숨은장소·꿀팁 보기, 필터, 검색, 지도, 골라주기, TIP 카드는 그대로 되고,
> **리뷰 · 추천/비추천 · 실시간 채팅 · 정보 제보 · AI 도우미**는 아래 방법으로 내 PC에서 실행해야 쓸 수 있습니다.

## 기능

- **맛집 95곳** — 배달앱처럼 카테고리(한식·중국집·분식 등)로 고르기, 가격(1인 8천 원 이하) 필터, 정렬
- **뭐 먹지? 골라줘** — 조건을 고르면 룰렛처럼 한 곳을 골라 줌 (추천 많은 곳이 조금 더 잘 나옴)
- **숨은장소 81곳** — 권역·용도 필터, 용도별 그림 표지, 카카오맵 로드뷰 링크
- **지도로 보기** — 맛집·숨은장소를 지금 고른 필터 그대로 지도 핀으로 (학교 앞 / 충주 전체)
- **생활꿀팁 74개 · 자유 59개** — 주제별 필터
- **💡 TIP 카드** — 게임 로딩 화면처럼 10초마다 꿀팁이 바뀜
- **리뷰 · 추천/비추천** — 카드마다 리뷰(닉네임+비밀번호) 작성·삭제, 한 곳당 한 번 추천/비추천
- **실시간 익명 수다** — 접속한 사람끼리 채팅, 메시지는 20초 뒤 사라지고 저장되지 않음
- **정보 제보** — 틀린 정보·새 장소를 보내면 서버의 `storage/reports.json`에 쌓임
- **✦ AI 도우미** — 내 PC의 로컬 LLM(Ollama + EXAONE 3.5)에게 묻기. 가게 이름·가격 같은 사실은 AI가 아니라 데이터 카드로 보여 줘서 지어내지 않음
- **관리자 페이지** — 제보함·리뷰 관리·추천 관리·현황판. 서버를 켠 PC에서, 정해 둔 키를 입력해야만 열림
- 검색, 다크 모드, 휴대폰 화면 지원

## 실행 방법

[Node.js](https://nodejs.org)(18 이상)가 필요합니다. 따로 설치할 패키지는 없습니다.

- Windows: `실행하기.bat` 더블클릭
- 직접 실행: `node server.js` 후 브라우저에서 <http://localhost:3100>

같은 와이파이에 있는 사람은 서버 창에 나오는 `http://192.168.x.x:3100` 주소로 접속할 수 있습니다.
포트를 바꾸려면 `PORT=4000 node server.js` 처럼 실행하세요.

### AI 도우미 켜기 (선택)

1. [Ollama](https://ollama.com) 설치
2. `ollama pull exaone3.5:2.4b`
3. 서버를 켜면 오른쪽 아래 "AI에게 물어보기"가 동작합니다. (다른 모델: `AI_MODEL=exaone3.5:7.8b node server.js`)

### 관리자 키 정하기 (선택)

`node tools/set-admin-key.js`로 키를 정하면 `admin-key.local.json`이 생깁니다(키 자체가 아니라 해시만 저장, 저장소에는 올리지 않음).
서버를 다시 켠 뒤 사이트 화면에서 그 키를 입력하면 관리자 페이지로 들어갑니다. 이 파일이 없으면 관리자 기능은 꺼져 있습니다.

## 데이터 고치기

1. 정리된 엑셀(`…_데이터.xlsx`)을 수정
2. `데이터-갱신하기.bat`에 엑셀 파일을 끌어다 놓기 (처음 한 번은 `exceljs`를 설치하느라 인터넷 필요)
3. 브라우저 새로고침

엑셀 없이 `public/data/places.json`을 직접 고쳐도 됩니다. TIP 카드 문장은 `public/data/tips-qa.json`에 있습니다.

## 폴더 구성

```
server.js              웹페이지 + 리뷰/추천·제보·관리자 API + 실시간 채팅 (Node 기본 모듈만 사용)
ai.js                  AI 도우미 (데이터에서 후보 찾기 → Ollama 에게 고르기·한마디 맡기기)
public/
  index.html           화면
  style.css            디자인
  app.js               필터·검색·지도·리뷰·골라주기·팁·제보·AI·채팅
  admin.html           관리자 페이지 (보기 전용판에는 올라가지 않음)
  data/places.json     맛집·숨은장소·생활꿀팁·자유 데이터
  data/tips-qa.json    TIP 카드 문장
  data/coords.json     지도·로드뷰 좌표 (학생들이 낸 네이버 지도 링크에서 뽑음)
tools/update-data.js   엑셀 → places.json 변환
tools/set-admin-key.js 관리자 키 정하기
storage/               리뷰·추천·제보 기록 (실행하면 생김, 저장소에는 올리지 않음)
```

## 데이터 출처와 참고

- 맛집·숨은장소·꿀팁은 수업 1주차에 학생들이 직접 조사해 낸 내용을 정리한 것입니다. 원본에 없던 값은 지어내지 않고 "확인 안 됨"으로 두었습니다.
- 가게 정보(가격, 영업시간 등)는 조사 시점(2026년 10월) 기준이라 지금과 다를 수 있습니다.
- 지도 링크는 네이버 지도, 로드뷰 링크는 카카오맵으로 연결됩니다. 지도 그림은 © OpenStreetMap 입니다.
